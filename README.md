# Privacy Policy — IDection Player

This repository exists only to publish the privacy policy of the Android app
**IDection Player**, which Google Play requires to be available at a public,
stable URL.

- **Published at:** https://skrvaxdev-source.github.io/idection-player-privacidad/
- **Contents:** a single self-contained `index.html` (no dependencies other than
  Google Fonts).

The name includes `player` on purpose: this policy covers **only** IDection
Player. If another app from the suite is published later (for example IDection
Files), it will have its own policy, its own repository and its own URL — one
app, one policy.

There is no app code here. The commit history of this repository is the
policy's changelog: every new version is recorded with its date.
